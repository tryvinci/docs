## Prerequisites

- A Vinci account. Sign in at [app.tryvinci.com/studio](https://app.tryvinci.com/studio).
- Credits on the account, or your own provider account. Your balance shows on the **Credits** page in the Studio. See [Make stills and clips on your own accounts](/learn/your-own-accounts) to run on your own account for 0 Vinci credits.

## 1) Make a still in the Studio

1. Open the **Image** page.
2. Write a prompt, for example "A ceramic mug on a wooden table, soft window light".
3. Pick a model and an aspect ratio. The price shows on the **Generate** button.
4. Click **Generate**.

See [Make four product stills from one prompt](/learn/four-stills-from-one-prompt) for more.

## 2) Turn it into a clip

1. On the **Image** page, hover the still and click **Animate**. The **Video** page opens with the still as the **Start** frame.
2. Ask for one slow camera move, for example "slow push-in".
3. Pick the **Duration** and click **Generate**. The clip shows in **History** when the model is done.

See [Turn a still into a 6-second clip](/learn/animate-a-still) for more.

## 3) Connect your agent

Claude Code, claude.ai, Cursor and other MCP clients can use the same Studio. You sign in with your Vinci account. You do not need an API key.

```bash
claude mcp add --transport http vinci https://app.tryvinci.com/mcp
```

Then type `/mcp` in Claude Code, select **vinci**, then select **Authenticate**. See [Use Vinci from your agent](/agents) for the other clients and the tools.
