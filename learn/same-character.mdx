An AI character that changes face between shots breaks the story. A locked sheet, one fixed description and chained frames keep them the same person.

<Columns cols={2}>
  <Card title="What you get" icon="flag-checkered">
    A character who looks like the same person in every shot.
  </Card>
  <Card title="Time to read" icon="clock">
    About 4 minutes. Each step works with any toolset.
  </Card>
</Columns>

## What you need

- An image model that accepts reference images
- An image-to-video model that takes a first frame
- About ten minutes to build the character sheet

## Steps

<Steps>
  <Step title="Make a character sheet">
    Generate the character front, side and three quarter on a plain background. This sheet is the reference for everything that follows.
  </Step>
  <Step title="Lock the outfit and props">
    Write one description of the face, hair, outfit and props, and paste it unchanged into every prompt. Do not paraphrase it.
  </Step>
  <Step title="Reference every shot">
    Feed the same sheet images into every generation, not only the first one. Each shot should start from the reference, not from the shot before it.
  </Step>
  <Step title="Chain your shots">
    Use the last frame of one shot as the first frame of the next, so the character carries across the cut.
  </Step>
  <Step title="Check side by side">
    Put every shot in a row and compare faces at the same size. Regenerate the one that drifts rather than trying to fix it in the edit.
  </Step>
</Steps>

## Try it

Fill in the parts of the character once. Copy the locked line into every prompt and change only the scene.

<CharacterLock />

<Tip>
  **Keep the camera simple.** Big face turns are where models lose identity. Prefer small moves and three quarter angles over full profile turns.
</Tip>

<Warning>
  **Avoid this: rewriting the description.** A new prompt gives you a new person. Copy the locked description every time, even when only the scene changes.
</Warning>

export const CharacterLock = () => {
  const [f, setF] = useState({ name: "Maya", face: "oval face, warm brown eyes", hair: "short dark brown hair", outfit: "teal jacket over a cream tee", props: "round black glasses" });
  const [scene, setScene] = useState("reading in a sunlit cafe");
  const [copied, setCopied] = useState(false);
  const lock = `${f.name}: ${f.face}, ${f.hair}, wearing a ${f.outfit}, ${f.props}.`;
  const prompt = `${lock} Scene: ${scene}. Match the character sheet exactly.`;
  const inp = { width: "100%", padding: 8, borderRadius: 8, border: "1px solid rgba(127,127,127,.35)", background: "transparent", color: "inherit", font: "inherit" };
  const copy = () => { try { navigator.clipboard.writeText(prompt); setCopied(true); setTimeout(() => setCopied(false), 1500); } catch (e) {} };
  return (
    <div className="not-prose" style={{ border: "1px solid rgba(127,127,127,.25)", borderRadius: 14, padding: 16, display: "grid", gap: 12 }}>
      <div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(180px, 1fr))", gap: 10 }}>
        {Object.keys(f).map((k) => (
          <label key={k} style={{ display: "grid", gap: 4, fontSize: 13, textTransform: "capitalize" }}>{k}
            <input value={f[k]} onChange={(e) => setF({ ...f, [k]: e.target.value })} style={inp} />
          </label>
        ))}
      </div>
      <div style={{ fontSize: 13, opacity: 0.7 }}>Locked line (never edit this between shots)</div>
      <div style={{ padding: 12, borderRadius: 10, background: "rgba(33,218,210,.12)", fontFamily: "ui-monospace, monospace", fontSize: 13 }}>🔒 {lock}</div>
      <label style={{ display: "grid", gap: 4, fontSize: 13 }}>This shot's scene (the only part that changes)
        <input value={scene} onChange={(e) => setScene(e.target.value)} style={inp} />
      </label>
      <div style={{ padding: 12, borderRadius: 10, border: "1px dashed rgba(127,127,127,.4)", fontFamily: "ui-monospace, monospace", fontSize: 13 }}>{prompt}</div>
      <button onClick={copy} style={{ justifySelf: "start", padding: "6px 14px", borderRadius: 8, border: "1px solid rgba(127,127,127,.35)", background: "transparent", color: "inherit", font: "inherit", cursor: "pointer" }}>{copied ? "Copied" : "Copy prompt"}</button>
    </div>
  );
};
