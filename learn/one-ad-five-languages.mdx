Your best ad only speaks one language. Here is how to localise it without a reshoot, while keeping the brand sounding like itself.

<Columns cols={2}>
  <Card title="What you get" icon="flag-checkered">
    The same ad localised for five markets.
  </Card>
  <Card title="Time to read" icon="clock">
    About 4 minutes. Each step works with any toolset.
  </Card>
</Columns>

## What you need

- A finished master ad
- A native speaker per language for the script
- A voice model, and lip-sync for on-camera shots

## Steps

<Steps>
  <Step title="Lock the master cut">
    Finish the ad in one language first. Every change after this point has to be made five times.
  </Step>
  <Step title="Translate for speech, not for print">
    Have each script adapted by someone who speaks the language, so lines fit the same timing and sound natural out loud.
  </Step>
  <Step title="Voice each version">
    Generate the voiceover per language with the same voice, or a consented clone of your presenter, so the brand sounds consistent.
  </Step>
  <Step title="Lip-sync the on-camera shots">
    Where someone speaks on screen, run lip-sync so mouth movement matches the new audio.
  </Step>
  <Step title="Swap on-screen text and captions">
    Replace every caption, title and end card per language, and check that longer words still fit the layout.
  </Step>
</Steps>

<Tip>
  **Leave room in the timing.** Some languages run longer. Leave a beat of breathing room in the master so translated lines fit.
</Tip>

<Warning>
  **Avoid this: translating the captions only.** Subtitles alone leave the voice in the original language. If the ad is voice-led, localise the voice too.
</Warning>

## Before you publish

- [ ] Lock the master cut
- [ ] Translate for speech, not for print
- [ ] Voice each version
- [ ] Lip-sync the on-camera shots
- [ ] Swap on-screen text and captions
