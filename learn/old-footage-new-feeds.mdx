A video from a few years ago can still earn attention. Pull the best ten seconds, upscale it, reframe it to vertical and give it a first line made for now.

  <Card title="What you get" icon="flag-checkered">

  </Card>
  <Card title="Time to read" icon="clock">
    About 4 minutes. Each step works with any toolset.
  </Card>
</Columns>

## What you need

- The original footage, at the best quality you still have
- An upscaler for video
- An editor that can crop to 9:16 and burn in captions

## Steps

<Steps>
  <Step title="Find the best moments">
    Watch the old footage and pull the strongest ten seconds. One clear moment beats a montage.
  </Step>
  <Step title="Upscale it">
    Upscale the clip so it holds up on a modern phone screen. Compare at full size on a phone, not on a laptop.
  </Step>
  <Step title="Reframe to vertical">
    Crop to 9:16 and keep the subject in the frame as they move. Check every second, not only the first frame.
  </Step>
  <Step title="Add a new hook">
    Put a new first line on screen so the clip feels made for now. Be honest that it is older footage if the date matters.
  </Step>
  <Step title="Caption and cut short">
    Burn in captions and keep it to fifteen to thirty seconds.
  </Step>
</Steps>

## Try it

Enter your footage size to see the 9:16 crop you get, and how much of the frame is left to follow the subject.

<ReframeCalc />

<Tip>
  **Check the rights.** Make sure you still have the rights to the music and the footage, and that the people in it are still happy for it to be used.
</Tip>

<Warning>
  **Avoid this: over-sharpening faces.** Pushing the upscale too far makes faces look plastic. Stop at the point where skin still has texture.
</Warning>

export const ReframeCalc = () => {
  const [w, setW] = useState(1920);
  const [h, setH] = useState(1080);
  const cw = Math.round((h * 9) / 16);
  const fits = cw <= w;
  const share = fits ? Math.round((cw / w) * 100) : 100;
  const travel = fits ? w - cw : 0;
  const inp = { width: 110, padding: 8, borderRadius: 8, border: "1px solid rgba(127,127,127,.35)", background: "transparent", color: "inherit", font: "inherit" };
  return (
    <div className="not-prose" style={{ border: "1px solid rgba(127,127,127,.25)", borderRadius: 14, padding: 16, display: "grid", gap: 14 }}>
      <div style={{ display: "flex", gap: 14, flexWrap: "wrap", alignItems: "end" }}>
        <label style={{ display: "grid", gap: 4, fontSize: 13 }}>Width (px)<input type="number" value={w} onChange={(e) => setW(Math.max(1, +e.target.value || 1))} style={inp} /></label>
        <label style={{ display: "grid", gap: 4, fontSize: 13 }}>Height (px)<input type="number" value={h} onChange={(e) => setH(Math.max(1, +e.target.value || 1))} style={inp} /></label>
      </div>
      <div style={{ position: "relative", width: "100%", maxWidth: 420, aspectRatio: `${w} / ${h}`, borderRadius: 10, background: "rgba(127,127,127,.18)", overflow: "hidden" }}>
        <div style={{ position: "absolute", top: 0, bottom: 0, left: `${(100 - share) / 2}%`, width: `${share}%`, border: "3px solid #21dad2", borderRadius: 6, boxSizing: "border-box" }} />
      </div>
      <div style={{ fontSize: 14, lineHeight: 1.6 }}>
        {fits ? <>A 9:16 crop is <b>{cw} × {h}</b>, which keeps <b>{share}%</b> of the width. The crop can slide <b>{travel}px</b> to follow the subject.{h < 1280 && <> The crop is under 1280px tall, so upscale before you publish.</>}</>
          : <>This footage is already taller than 9:16. Crop the height instead, or pad the sides.</>}
      </div>
    </div>
  );
};
