When a winning ad gets tired, you do not need a new campaign. Change one variable at a time and you get ten new tests from the same idea.

<Columns cols={2}>
  <Card title="What you get" icon="flag-checkered">
    A set of variants that each test one change.
  </Card>
  <Card title="Time to read" icon="clock">
    About 4 minutes. Each step works with any toolset.
  </Card>
</Columns>

## What you need

- An ad that already performs
- A way to track which variant changed what
- An image or video model for new scenes

## Steps

<Steps>
  <Step title="Name what made it win">
    Write down the hook, the product moment and the offer. Those stay. Everything else is a variable you can change.
  </Step>
  <Step title="Rewrite the first two seconds">
    Make three new openings: a question, a bold claim and a visual surprise. The hook is the cheapest thing to change and often the biggest lever.
  </Step>
  <Step title="Change the setting">
    Put the same product moment in three new scenes so the ad looks new without changing the message.
  </Step>
  <Step title="Vary the format">
    Cut 9:16, 4:5 and 1:1 versions, and a six second edit of the strongest beat.
  </Step>
  <Step title="Test one change at a time">
    Launch variants that differ in one thing, so you know which change moved the result.
  </Step>
</Steps>

## Try it

Plan your variants here. Each variant should change exactly one thing, so you can tell which change moved the result.

<VariantPlanner />

<Tip>
  **Keep a variant log.** Note what changed in each version. Next month you will know which levers work for your audience.
</Tip>

<Warning>
  **Avoid this: changing everything at once.** Fifty versions that differ in every way are not fifty tests. They are fifty guesses.
</Warning>

export const VariantPlanner = () => {
  const levers = ["Hook", "Scene", "Format", "Offer"];
  const [rows, setRows] = useState([[true, false, false, false], [false, true, false, false], [false, false, true, false], [true, true, false, false]]);
  const toggle = (r, c) => setRows(rows.map((row, i) => (i === r ? row.map((v, j) => (j === c ? !v : v)) : row)));
  const add = () => setRows([...rows, [false, false, false, false]]);
  return (
    <div className="not-prose" style={{ border: "1px solid rgba(127,127,127,.25)", borderRadius: 14, padding: 16, display: "grid", gap: 10, overflowX: "auto" }}>
      <div style={{ display: "grid", gridTemplateColumns: "60px repeat(4, minmax(70px, 1fr)) minmax(140px, 1.4fr)", gap: 8, fontSize: 13, alignItems: "center", minWidth: 520 }}>
        <span />
        {levers.map((l) => <strong key={l}>{l}</strong>)}
        <strong>Result</strong>
        {rows.map((row, r) => {
          const n = row.filter(Boolean).length;
          return [
            <span key={"v" + r}>V{r + 1}</span>,
            ...row.map((on, c) => (
              <button key={r + "-" + c} type="button" aria-label={"V" + (r + 1) + " " + levers[c]} onClick={() => toggle(r, c)}
                style={{ height: 34, borderRadius: 8, border: on ? "2px solid #21dad2" : "1px solid rgba(127,127,127,.3)", background: on ? "rgba(33,218,210,.18)" : "transparent", color: "inherit", font: "inherit", cursor: "pointer" }}>
                {on ? "New" : "Same"}
              </button>
            )),
            <span key={"s" + r} style={{ color: n === 1 ? "#1a9c96" : "#ef6b62", fontWeight: 600 }}>{n === 1 ? "Clean test" : n === 0 ? "Same as the winner" : "Changes " + n + " things"}</span>,
          ];
        })}
      </div>
      <button type="button" onClick={add} style={{ justifySelf: "start", padding: "6px 14px", borderRadius: 8, border: "1px solid rgba(127,127,127,.35)", background: "transparent", color: "inherit", font: "inherit", cursor: "pointer" }}>Add variant</button>
    </div>
  );
};
