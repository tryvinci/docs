Most of the cost in AI video comes from clips that never get used. Five habits keep your spend on the shots that make the final cut.

## What you need

- An image model and an image-to-video model
- A short brief with the look you want
- A place to log what each generation cost

## Steps

<Steps>
  <Step title="Lock the look on a still">
    Get the frame right as a still image first. Stills are faster and cheaper to redo, so do your exploring there: composition, light, product placement.
  </Step>
  <Step title="Animate only the approved still">
    Feed the approved still to an image-to-video model as the first frame. The look is already decided, so the model only has to add motion.
  </Step>
  <Step title="Generate five seconds, not ten">
    Start every shot at the shortest length. Extend only the clips that work instead of paying for long takes you end up trimming.
  </Step>
  <Step title="Check the price before you run">
    Models charge very differently for similar shots. Compare the price per second for the shot you need before you press generate.
  </Step>
  <Step title="Keep a receipt per project">
    Log what every still, clip and upscale cost. You will know what each finished ad really cost and where the money went.
  </Step>
</Steps>

<Tip>
  **One camera move per clip.** Ask for a single move, like a slow push-in. Fewer moves in a prompt means fewer retries.
</Tip>

<Warning>
  **Avoid this: animating too early.** The expensive mistake is generating the whole video before anyone has approved the look. Still, approve, then animate.
</Warning>

## Before you publish

- [ ] Lock the look on a still
- [ ] Animate only the approved still

export const RetryCostCalculator = () => {
  const [shots, setShots] = useState(4);
  const [tries, setTries] = useState(4);
  const [still, setStill] = useState(0.05);
  const [perSec, setPerSec] = useState(0.1);
  const [len, setLen] = useState(5);
  const clip = perSec * len;
  const videoFirst = shots * tries * clip;
  const stillFirst = shots * (tries * still + clip);
  const max = Math.max(videoFirst, stillFirst, 0.0001);
  const money = (v) => "$" + v.toFixed(2);
  const row = (label, value, set, min, max, step, fmt) => (
    <label style={{ display: "grid", gap: 4, fontSize: 14, minWidth: 0 }}>
      <span>{label}: <strong>{fmt(value)}</strong></span>
      <input type="range" min={min} max={max} step={step} value={value} onChange={(e) => set(Number(e.target.value))} />
    </label>
  );
  const bar = (label, v, color) => (
    <div style={{ display: "grid", gap: 4 }}>
      <div style={{ display: "flex", justifyContent: "space-between", fontSize: 13 }}><span>{label}</span><strong>{money(v)}</strong></div>
      <div style={{ height: 14, borderRadius: 7, background: "rgba(127,127,127,.18)" }}><div style={{ height: 14, borderRadius: 7, width: (v / max) * 100 + "%", background: color }} /></div>
    </div>
  );
  return (
    <div className="not-prose" style={{ border: "1px solid rgba(127,127,127,.25)", borderRadius: 14, padding: 16, display: "grid", gap: 16 }}>
      <div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(200px, 1fr))", gap: 14 }}>
        {row("Shots in the ad", shots, setShots, 1, 12, 1, (v) => v)}
        {row("Attempts until a shot is approved", tries, setTries, 1, 10, 1, (v) => v)}
        {row("Price per still", still, setStill, 0.01, 0.5, 0.01, money)}
        {row("Video price per second", perSec, setPerSec, 0.01, 1, 0.01, money)}
        {row("Clip length", len, setLen, 5, 10, 5, (v) => v + "s")}
      </div>
      {bar("Animate every attempt", videoFirst, "#ef6b62")}
      {bar("Explore on stills, animate the approved one", stillFirst, "#21dad2")}
      <div style={{ fontSize: 14 }}>Difference: <strong>{money(Math.max(0, videoFirst - stillFirst))}</strong> for this ad.</div>
    </div>
  );
};
